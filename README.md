# C++ salary market dashboard

Публичный интерактивный обзор вакансий Senior C++ для России, Лондона и Швейцарии.

## Автоматическое обновление

GitHub Actions запускает обновление каждый понедельник в 09:00 по Москве, а также после изменений в `main` и вручную из вкладки Actions. Workflow собирает вакансии, применяет правила фильтрации и дедупликации кодом, пересобирает страницу, коммитит новый снимок и публикует GitHub Pages. ИИ при сборе и расчётах не используется.

Для Headcount Labs и SuperJob в `Settings → Secrets and variables → Actions` нужны secrets:

- `HEADCOUNTLABS_API_KEY`
- `SUPERJOB_APP_SECRET`

Если ключи не заданы, workflow продолжит обновлять публичные источники без этих API, сохраняя последний успешный снимок API.

## Публичные источники

Еженедельно также опрашиваются открытые страницы работодателей в Greenhouse, Lever и Ashby, публичные превью четырёх Telegram-каналов, RSS HeadHunter, RSS SwissDevJobs и API Himalayas. В дашборд попадают вакансии с явной C++-специализацией и целевым рынком; удалённые роли включаются только при явном допуске кандидатов из соответствующей страны. Для расчёта зарплаты код требует указанную сумму, валюту и период.

Каждая вакансия сохраняет ссылку на первичный источник. Если источник временно недоступен, workflow оставляет его последний успешный снимок. В Telegram факт публикации не подтверждает, что вакансия ещё открыта; для этого источника актуальность оценивается по дате поста, а закрытые вакансии могут сохраниться до 90 дней.

Сайты, чьи условия запрещают автоматический сбор или повторное использование данных, в подключение не включались. Ключи HeadHunter пока не нужны: RSS используется как публичный резервный источник и прекращает запросы при ответе с ограничением доступа.

## Локальный запуск

```sh
python3 work/api_connector/refresh.py
```

API-ключи задаются в `work/api_connector/.env` на локальном устройстве или через переменные окружения. Файл `.env` исключён из Git.
